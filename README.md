\# PROJECTPULSE – Student Project \& Task Management Platform



PROJECTPULSE is a Django-based student project and task management platform designed to help students organize projects, track tasks, monitor deadlines, and view project progress from a centralized dashboard.



The application uses Django with SQLite for the backend and database, along with HTML, CSS, and JavaScript for the user interface.



\---



\## 📌 Project Overview



PROJECTPULSE provides students with a simple platform to:



\- Create and manage projects

\- Add and manage tasks within projects

\- Track task status and priority

\- Monitor project completion progress

\- Identify overdue tasks

\- Search and filter projects

\- Edit and delete projects and tasks

\- Manage user registration and authentication

\- View project and task information through a dashboard



\---



\## 🚀 Features



\### 🔐 User Authentication



\- User registration

\- User login

\- User logout

\- User-specific project management



\### 📁 Project Management



Users can:



\- Create projects

\- View project details

\- Edit projects

\- Delete projects

\- Set project start dates and deadlines

\- Set project status

\- Track project creation and update times



\### ✅ Task Management



Tasks can be managed within projects with:



\- Task title

\- Description

\- Priority

\- Status

\- Deadline

\- Creation date

\- Update date



Users can create, edit, update, and delete tasks.



\### 📊 Dashboard



The dashboard provides project and task statistics including:



\- Total Projects

\- Active Projects

\- Completed Projects

\- Pending Tasks

\- Overdue Tasks
